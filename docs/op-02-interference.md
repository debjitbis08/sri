# OP-02: a first bounded interference certificate

Status: PARTIAL. The witness and minimality below are exact for a restricted
class. They do not establish intrinsic nonadditivity or intelligence.

## Declared semantics and independent control

Fix a finite state set S with distinguished quiescent state 0 and a commutative,
associative binary operation with identity 0. State indices are categorical
labels, never numeric output scores. Two distinct clamped satellite nodes feed
one distinct stateless core through optional directed edges. An absent edge
transmits 0; a present edge transmits its satellite state unchanged. No feedback,
self-loops, temporal memory, graded weights, or satellite-to-satellite edges
are allowed in this first class.

For transmitted states a,b the core state is a*b. The observable O(s) is the
empty set when s=0 and the singleton {s} otherwise. This full categorical
signature is fixed for every candidate before searching; it does not privilege
a particular active label. The independent control is the union of signatures
from the two isolated runs: B(a,b)=O(a*0) union O(0*b). An interference witness
means O(a*b) != B(a,b). This control records which distinct active states occur
in independent runs; it deliberately discards multiplicity.

## Two candidate tables and a negative control

Rows and columns follow state order; 0 is quiescent in each table.

| Operation | State order | Rows |
| --- | --- | --- |
| XOR cancellation | 0, a | (0,a); (a,0) |
| Saturating accumulation | 0, a, b | (0,a,b); (a,b,b); (b,b,b) |
| OR negative control | 0, a | (0,a); (a,a) |

All three are commutative monoids. XOR is addition modulo two. Saturating
accumulation is min(2,x+y) under indices 0,1,2: associativity follows because
both bracketings equal min(2,x+y+z). OR is Boolean join.

With two inputs a,a and both edges present, XOR has empty joint signature
versus independent {a}; saturation has joint {b} versus independent {a}.
OR agrees with its independent control for every input pair.

A bijective state renaming preserving the distinguished quiescent state maps
both signatures by the same bijection. Set union commutes with this mapping,
and equality/inequality is preserved. Thus these witnesses cannot be created
or removed by assigning different numeric labels to the same states.

## Scoped minimality and exhaustive certificate

The search generates every labeled commutative identity table on 1, 2, and 3
states. The remaining n(n-1)/2 cells vary freely, yielding respectively 1, 2,
and 27 tables. Each table is checked for associativity on every triple. The
surviving 1, 2, and 9 monoids are evaluated on every ordered satellite input
pair and all four edge masks: 4, 32, and 324 cases respectively. Results are
in [the frozen report](../reports/interference.json), generated by
`python -m experiments.interference`. There is no execution cap; status
`complete` applies only to these declared bounds.

One state cannot witness interference: all signatures are empty. With no
edge or one edge the identity law makes the joint signature exactly the
independent signature, for any state-set size. XOR supplies a witness with
two states and two edges. Hence these are the smallest state and edge counts
in this class. Three distinct nodes are required by the class definition
(two satellites and one core); this is not an enumeration of all smaller
possible architectures. The report finds 1 binary and 26 ternary witness
cases, all with two edges.

## Termination scope

The core response requires one table lookup. With clamped inputs, repeated
core updates produce the same state, regardless of initial core state. This
proves a unique core fixed point after at most one update in this feed-forward
class. There is no claim about recurrent networks, changing inputs, feedback,
or asynchronous propagation through deeper graphs (OP-03 remains open).

## Limits and next obligations

XOR is linear over GF(2), and saturated accumulation is ordinary addition
followed by saturation. Neither disproves every possible additive explanation.
The control is a declared set-union model, not a universal notion of independence.
A distinct-input pair can also differ merely because one core label cannot
represent a two-element independent signature. The selected equal-input
witness avoids that cardinality issue but still relies on the control's
choice to discard multiplicity. A multiset or algebra-aware control could
explain these responses. These are elementary controls for further research,
not a new algebra or evidence of useful collective inference.

Next: compare multiplicity-preserving and algebra-aware controls, seek a
witness beyond linear cancellation and saturation, and introduce graded
couplings and recurrent dynamics with explicit stopping semantics. Milestone
0 reporting hardening remains outstanding; this experiment does not change
the original reachability report or its claims.
